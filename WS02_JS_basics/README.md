# Workshop 02 – JavaScript Basics

This workshop focuses on the basic concepts of JavaScript and connecting JavaScript to an HTML page.

## Folder Structure

```text
WS02_JS_basics/
├── index.html
├── README.md
└── js/
    └── script.js

Exercises
Exercise 1 – Developer Tools and Console

Practised using the browser Developer Tools and Console with:

console.log()
alert()
observing JavaScript error messages
Exercise 2 – Variables

Created variables using const and let for:

name
age
favourite animal

Printed the values and a complete sentence to the Console.

Exercise 3 – User Input

Used prompt() to ask the user for their name and printed a greeting to the Console.

Exercise 4 – Conditionals

Used prompt() to ask for the user's age and created an if / else statement to determine whether the user is an adult or under 18.

Exercise 5 – Functions

Created a function called greetUser() that receives a name as a parameter and prints a greeting.

Exercise 6 – JavaScript Button

Connected JavaScript to the HTML page by adding a button and using an event listener to display a message when the button is clicked.
```

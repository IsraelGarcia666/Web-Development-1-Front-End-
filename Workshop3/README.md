# Workshop 3 – JavaScript Events and DOM Scripting

This workshop focuses on JavaScript events, DOM manipulation, form handling, keyboard events, and browser APIs.

## Exercises

### Exercise 1 – Basic Click Events

- Used inline `onclick` events
- Displayed an alert message
- Created an HTML table dynamically with JavaScript
- Used template strings and `document.querySelector()`

### Exercise 2 – Event Listeners and DOM Manipulation

- Used `mouseover`
- Used `addEventListener()`
- Changed element text and styles dynamically

### Exercise 3 – Input Events

- Used `focus`, `blur`, and `input` events
- Created a live character counter
- Created a live text preview

### Exercise 4 – Form Submission

- Used the `submit` event
- Used `event.preventDefault()`
- Validated feedback length
- Displayed success and error messages

### Exercise 5 – Keyboard Events

- Used the `keydown` event
- Read `event.key`
- Read `event.code`
- Updated page content based on keyboard input

### Bonus – Geolocation API

- Used the browser Geolocation API
- Retrieved latitude and longitude
- Created a Google Maps URL dynamically
- Opened the user's location in Google Maps

# Workshop 04 – JavaScript DOM Scripting

This workshop focuses on manipulating HTML elements with JavaScript, handling user interactions, creating dynamic content and working with forms.

## Exercises

### Task 1 – Changing Content

- Selected HTML elements using `querySelector()`.
- Added event listeners to buttons.
- Modified text using `textContent`.
- Changed CSS classes using `classList.toggle()`.

**Bonus:**

- Added new sentences without replacing existing text.
- Implemented an interactive axolotl background with translucent content panels.

### Task 2 – Creating HTML Elements

- Created headings, paragraphs and images using JavaScript.
- Added elements to the DOM using `append()`.
- Implemented buttons to hide and show content.

### Task 3 – Selecting an Animal

- Created an interactive animal selection feature.
- Updated animal images, names and descriptions.
- Implemented mouse events and image highlighting.

### Task 4 – Animal Observations

- Collected user input through an HTML form.
- Validated form fields.
- Created table rows dynamically.
- Added buttons to delete individual observations.

## Additional Bonus Exercises

- Moving images with CSS classes
- Creating CSS animations
- Adding fade effects
- Removing elements from the DOM
- Selecting and looping through elements using `querySelectorAll()`
